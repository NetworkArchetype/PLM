# PLM Proof Package
## Pi-Lambda-Mu (PLM) — Complete Thesis, Proofs & Test Suite

### What Is This?

This package contains every artifact needed to independently verify the
PLM mathematical transform:

    S = ((pi * Y) * (lambda * X)) / (mu * C)

It includes:

- **Full academic thesis** (9 HTML chapters + CSS, viewable in any browser)
- **Python theorem prover** — verifies all 6 algebraic theorems to 80 decimal digits
- **Ruby theorem prover** — independent re-derivation using BigDecimal
- **Cirq quantum verification runner** — H-Rz(theta)-H circuit physics, Bell state, Grover 3-SAT, full pipeline
- **Master test runner** — orchestrates all provers + pytest + validation harness
- **PDF builder** — converts the HTML thesis to PDF (auto-detects Chrome/Edge/wkhtmltopdf/weasyprint)
- **Combined HTML** — single-file thesis for easy Print-to-PDF
- **Complete source code** — the entire PLM_APLIED repository

### Quick Start

```bash
# 1. Install Python dependencies
pip install cirq sympy pytest

# 2. Run ALL proofs (Python + Ruby + Cirq + pytest + validation)
python PROOF_PLM/run_all_tests.py

# 3. Run with verbose output
python PROOF_PLM/run_all_tests.py --verbose

# 4. Run just the Python theorem prover
python PROOF_PLM/prove_theorems_python.py

# 5. Run just the Ruby theorem prover
ruby PROOF_PLM/prove_theorems_ruby.rb

# 6. Run the Cirq quantum verification
python PROOF_PLM/run_cirq_verification.py

# 7. Run pytest unit tests
pytest -v

# 8. Run the validation harness
python validation_np_hard/run_validation.py

# 9. Run NP-hard benchmarks (optional, CPU-intensive)
python PROOF_PLM/run_all_tests.py --with-np

# 10. Build PDF
python PROOF_PLM/build_pdf.py

# 11. Skip optional runners
python PROOF_PLM/run_all_tests.py --skip-ruby --skip-cirq
```

### Proof Runners

#### Python Theorem Prover (`prove_theorems_python.py`)
Verifies all 6 PLM algebraic theorems using Python's `decimal.Decimal` with 80-digit precision. Also checks: PLM constant R computation, 100-run determinism, and guard rail enforcement (mu!=0, C>0, valid hex).

#### Ruby Theorem Prover (`prove_theorems_ruby.rb`)
Independent re-implementation using Ruby's `BigDecimal`. Verifies the same 6 theorems plus determinism and guard rails. Cross-language parity confirms the math is implementation-independent.

#### Cirq Quantum Verification (`run_cirq_verification.py`)
Six verification stages:
1. Circuit construction (H-Rz-H-Measure)
2. Quantum physics: p(|1>) = sin^2(theta/2), <Z> = cos(theta)
3. Full PLM quantum temporal pipeline (5-step time-series)
4. Grover 3-SAT demo (from validation_np_hard)
5. Bell state smoke test
6. Angle mapping verification (S -> theta mod 2pi)
